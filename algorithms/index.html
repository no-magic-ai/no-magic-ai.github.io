Algorithm Catalog

Single-file Python implementations of the algorithms that power modern AI. Most scripts train from scratch: some train one model and then run inference, others train alternative variants side by side and compare them. A few run untrained forward-pass mechanisms or non-learning algorithms. Each card shows the script's kind, data source and the paper card it is mapped to, including the catalog's adaptation note where the code differs from that paper. Read the source top-to-bottom like a tutorial.
